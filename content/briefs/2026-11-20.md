- **[Anthropic：股票在纳斯达克开始交易](https://www.nasdaq.com/newsroom/anthropic-marks-ipo-at-nasdaq)**（11/19，[纳斯达克新闻室](https://www.nasdaq.com/newsroom/anthropic-marks-ipo-at-nasdaq)；[公司定价公告](https://www.anthropic.com/news/anthropic-prices-initial-public-offering)）：这是对昨日定价公告的后续，不是重复同一条发行安排。Anthropic, PBC 此前宣布，A 类普通股首次公开发行定价为每股 83.00 美元，发行规模为 9.80 亿股，股票代码为 ANT。纳斯达克新闻室写明，该股已于 11 月 19 日（周四）在纳斯达克开始交易，开盘价为 111.50 美元。关于收盘价，本刊未见纳斯达克新闻室或公司官网给出正式数字；[CNBC](https://www.cnbc.com/2026/11/19/anthropic-ipo-ant-live-updates.html) 在美东时间 11 月 19 日 18:17 的更新中报道，该股当日收于 97.17 美元，较发行价上涨约 17%；[CBC](https://www.cbc.ca/news/business/anthropic-first-day-trading-9.7428367) 亦援引彭博数据，报道开盘 111.50 美元、盘中最高 115.10 美元、收盘 97.17 美元，涨幅 17.07%。公司定价公告仍写明，发行预计于 11 月 20 日交割，须满足惯例交割条件；至本次核验时，本刊不将交割写为已完成结果。以上开盘价以纳斯达克新闻室为准，收盘价与盘中最高价来自上述新闻报道，非本刊独立行情核验。

- **[Google：在 Gemini API 推出 Tool Retrieval 预览](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-tool-retrieval/)**（11/19，[官方博客](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-tool-retrieval/)）：Google 宣布，Tool Retrieval 已在 Gemini Interactions API 中以预览形式提供。开发者可在请求中加入 `tool_search`，并对希望暂缓加载的工具设置 `defer_loading: true`；模型仍能看到这些工具的名称与描述，但完整参数 schema 会在当前任务需要时再加载，并在同一次请求内完成查找、加载与函数调用。官方称，该功能没有单独收费，输入和输出仍按所用模型的标准价格计费；开启 `tool_search` 会增加一小块固定的输入 token，模型实际加载的 schema 则作为随后对话的输入计费。官方建议用自己的流量衡量能否省下 token。该功能适用于 Gemini 3.6 及更新型号（含所有 Gemini 4 型号），也可对远程 MCP 服务器设置按需加载。以上为厂商说明，未实测。

- **[OpenAI：介绍用 Codex 自动排查性能回退的 Performance Factory](https://openai.com/index/how-openai-performance-factory-keeps-chatgpt-fast/)**（11/19，[官方博文](https://openai.com/index/how-openai-performance-factory-keeps-chatgpt-fast/)）：OpenAI 介绍其内部的 Performance Factory：这是一套在云端运行、由 Codex 与其模型驱动的工作流系统，用于自动调查并处理性能回退。官方描述的第一条工作流是 Regression Workflow：性能告警触发后，一个 agent 负责调查并记录结论、提出供工程师审阅的修复；部署后再由另一个 agent 检查性能是否回到基线。官方称，在略超过三个月的时间里，该工作流跟踪了 1700 多次调查，并定位了 600 多个根因，相当于每天约 17 次自动调查。官方同时写明，目前修复仍需工程师审阅与合并，团队也在探索能否让 agent 走得更远。上述数量、流程与效果均为厂商自报，未实测。

- **[Microsoft：Edge 将 Aion Instruct 作为内置端侧模型，并开放 Prompt API 源站试用](https://blogs.windows.com/msedgedev/2026/11/19/hybrid-intelligence-on-the-web-introducing-aion-instruct-and-prompt-api-in-microsoft-edge/)**（11/19，[Microsoft Edge 官方博客](https://blogs.windows.com/msedgedev/2026/11/19/hybrid-intelligence-on-the-web-introducing-aion-instruct-and-prompt-api-in-microsoft-edge/)）：Microsoft 宣布三项更新：Aion Instruct 作为开放权重模型在 Hugging Face 上提供，并成为 Microsoft Edge 的内置小型语言模型，替换此前的 Phi-4-mini；Prompt API 进入源站试用（origin trial），站点可在正式版 Edge 中调用；实验性 Decisions API 仍在 Edge Canary 与 Dev 通道提供开发者预览，用于对文本做是非、选择或打分，并返回概率与置信度。官方称 Aion Instruct 为 23 亿参数，体积更小、速度更快、可覆盖更多设备，并在常见网页任务上与 Phi 质量相当；上述比较均为厂商自报，未实测。官方还写明，Edge 仅在站点或功能首次需要、且设备能够良好运行时才下载该模型，用户可在设置中关闭端侧 AI；该模型计划于今年晚些时候登陆 Windows。以上为厂商说明，未实测。
