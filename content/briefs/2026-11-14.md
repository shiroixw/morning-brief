## 要闻

- **[英伟达：CEO 交接](https://nvidianews.nvidia.com/news/nvidia-announces-ceo-transition)**（11/12，[官方新闻稿](https://nvidianews.nvidia.com/news/nvidia-announces-ceo-transition)）：董事会宣布黄仁勋（Jensen Huang）已辞去总裁、首席执行官及董事职务，立即生效。现任执行副总裁兼首席财务官 Colette Kress 出任临时 CEO，并继续兼任 CFO，直至产生正式继任者；董事会将同时考虑内部与外部人选。董事会还任命 Harvey C. Jones 为首任董事长。官方声明未说明辞职原因，并对黄仁勋的贡献表示感谢；同时表示预计公司运营、客户承诺与产品路线图将不受影响。公司仍按原定计划于 11/17 太平洋时间约 13:20（北京时间 11/18 凌晨约 5:20）发布 2027 财年第三季度财报。以上为官方公告。
  <span hidden data-article-id="2026-11-14-nvidia-ceo-transition" data-tags="科技,AI"></span>
- **[OpenAI：Daybreak Red Team 与 Defense Factory](https://openai.com/cyber-at-the-frontier/)**（11/12，[官方活动页](https://openai.com/cyber-at-the-frontier/) 与产品页）：在 Cyber at the Frontier 活动上发布两款安全产品。[Daybreak Red Team](https://openai.com/daybreak/red-team/) 面向 Web 应用，由一组智能体做渗透测试、核验漏洞，并检查补丁是否挡住相应利用；官方称测试在隔离环境中进行，并由 Guardian review 控制可触及的应用与端点，目前开放 early access 申请。[Daybreak Defense Factory](https://openai.com/daybreak/defense-factory/) 用于调查安全发现并起草补丁，官方写明须由工程师审阅、测试后再合并，不会自动上线。能力与效果为厂商说明，未实测。
  <span hidden data-article-id="2026-11-14-openai-daybreak" data-tags="AI,科技,开发"></span>
- **[Anthropic：自托管 Claude Managed Agents](https://claude.com/resources/articles/self-hosted-claude-managed-agents)**（11/12，官方产品说明）：私人测试向符合条件的客户开放，需通过 Anthropic 客户团队申请。官方称可把 Managed Agents 的控制面放进自有云或机房，自行运行服务端、数据库，以及智能体执行 shell 与文件工具的 worker；会话记录留在自有数据库，凭证也可放入自有密钥管理。模型请求可发往 Anthropic、Amazon Bedrock、Google Agent Platform、Microsoft Foundry 或自建网关。若已有零数据保留（ZDR）协议，官方称对这类请求的效力与普通 Messages API 相同。以上为厂商说明，未实测。
  <span hidden data-article-id="2026-11-14-anthropic-self-hosted-managed-agents" data-tags="AI,开发,科技"></span>
- **[Vercel：AI Gateway 上线 Parallel Decisions](https://vercel.com/changelog/parallel-decisions-now-available-on-ai-gateway-for-free)**（11/13，官方 Changelog）：将 Parallel 的 Parallel Decisions Fast 接入 AI Gateway，模型名为 `parallel/parallel-decisions-fast`，官方称无需单独的 Parallel 账号，并可免费使用至 2026-11-23。它会检索公开网页，为是/否、选择题或量表题返回概率与引用来源，便于核验公司、产品、政策等会变化的信息。官方写明引用针对整次请求，并不一一对应到每道题。效果与免费期限为厂商说明，未实测。
  <span hidden data-article-id="2026-11-14-vercel-parallel-decisions" data-tags="AI,开发,产品"></span>

以上为 11/12 与 11/13 的官方公告，事实与厂商自报已分开标注。具体能力、安排与性能以各官方为准。
