## 要闻

- **[Cloudflare：Codex Agent Harness](https://developers.cloudflare.com/changelog/post/2026-11-09-codex-harness/)**（11/9，官方 Changelog）：Cloudflare 发布实验性示例，可在 Durable Objects 中运行 Codex Agent 循环。Codex 的 Rust turn-processing 代码编译为 WebAssembly，配合 Agents SDK 的 Tasks、Sessions、Streams、Workspace 能力实现持久化存储与中断恢复。（未实测）
- **[Automattic 推出 Spacefast](https://www.prnewswire.com/news-releases/automattic-launches-spacefast-a-new-company-that-gets-apps-and-websites-live-in-seconds-302933038.html)**（11/9，厂商发布稿）：Automattic 成立新公司 Spacefast，让用户继续使用 ChatGPT、Claude、Cursor 等 AI 工具，由 Spacefast 提供数据库、域名与部署环境，实现「秒级上线」。已在 Claude、ChatGPT、Grok Bot 等平台提供官方插件，支持 MCP 与 CLI。个人版免费起步，Pro 版 $15/月/成员。（未实测，厂商定价与功能以官网为准）
- **[HoundDog.ai 发布 ProtoMap](https://www.prnewswire.com/news-releases/hounddogai-launches-protomap-to-show-the-blast-radius-of-every-grpc-and-protobuf-change-across-monorepos-and-microservices-302931453.html)**（11/9，厂商发布稿）：面向 gRPC / Protobuf 的服务依赖图引擎，Rust 扫描器从源码构建服务拓扑，帮助工程师和 AI Agent 在修改前了解影响范围。厂商称在 500 万行代码基准测试中，Claude Code 速度提升 6.4 倍、成本降低 5.3 倍。提供免费自托管版与企业版。（未实测，数据来自厂商）
- **[Cloudsmith 宣布 AI Skills Registry](https://cloudsmith.com/company/press/ai-skills-registry)**（11/9 KubeCon，厂商发布稿）：Cloudsmith 推出 AI Agent Skills 仓库，支持托管、发布、分发和治理 AI 编码 Agent 使用的 Skill 文件（SKILL.md 及相关脚本）。提供版本控制、上游代理、允许/拒绝列表与审计日志，帮助企业管控 Agent 软件供应链。（未实测）
