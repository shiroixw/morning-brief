> 核验日期：2026-11-12 北京时间。以下官方更新均标注 11/11 发布，产品未实测。

## 要闻

- **[Google：Gemini Decisions API](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/)**（11/11，官方博客）：推出面向封闭集决策的新接口，由新模型 Gemini Decision 1（`gemini-decision-1`）驱动，可在 Google AI Studio 的 Gemini API 中使用。官方称一次请求可对同一份多模态输入（文本、图片、音频、视频、PDF，最长 256K tokens）并行评估最多 1,000 道是/否、选择题或量表题，在单次前向计算中返回概率与置信度，不按输出 token 计费；标价为每百万输入 token 0.10 美元，并提供用于原型的免费额度。延迟、价格与基准表现为厂商说明，未实测。同一天，[Vercel AI Gateway 也已上线该模型](https://vercel.com/changelog/gemini-decision-1-now-available-on-ai-gateway)，模型名为 `google/gemini-decision-1`。
  <span hidden data-article-id="2026-11-12-gemini-decisions-api" data-tags="AI,科技,开发"></span>
- **[AWS Emulator 正式可用](https://aws.amazon.com/blogs/aws/test-your-applications-against-aws-locally-with-aws-emulator/)**（11/11，[AWS News Blog](https://aws.amazon.com/blogs/aws/test-your-applications-against-aws-locally-with-aws-emulator/) 与 [What's New](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-emulator-now-available/)）：可在本机或 CI 中运行的本地模拟器，用现有 AWS SDK / CLI，经本地 HTTPS 端点调用与云上相同的 API。官方称无额外服务费，源码以 CC0 1.0 发布；Linux 可装 RPM 或 Debian 包，macOS 与 Windows 需自行用文档中的 Dockerfile 运行，不提供现成镜像。AWS 还写明：模拟器由智能体根据公开 API 模型生成并维护；默认不按云上方式评估 IAM 策略，每个实例相当于单一账号，与真实 AWS 的一致程度因服务而异，未实现的操作返回 501。以上均为厂商说明，未实测。
  <span hidden data-article-id="2026-11-12-aws-emulator" data-tags="科技,开发"></span>
- **[Modern Web Guidance 1.0](https://developer.chrome.com/blog/beyond-code-generation)**（11/11，Chrome 开发者博客）：面向编码 Agent 的技能与指南正式到 1.0，覆盖 200 余个实际用例，引导使用原生 HTML/CSS 而非过时的 JavaScript 变通。由 Chrome、Edge、Firefox 与 MDN 等共同维护；可用 `npx modern-web-guidance@latest install` 安装，并提供 CLI 检索指南。官方称在其公开评测中，未引导的前沿模型约通过 60% 的现代 Web 检查，使用该指南后约升至 80%–90%。评测数据为厂商说明，未实测。
  <span hidden data-article-id="2026-11-12-modern-web-guidance" data-tags="开发,科技"></span>
以上均为 11/11 发布的官方公告，事实与编辑看法已分开标注。具体能力、定价与性能以各官方为准。
