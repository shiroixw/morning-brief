## 要闻

- **[OpenAI：发布 GPT-6.2 Astra 与 Sol](https://openai.com/index/introducing-gpt-6-2-astra-sol/)**（11/17，[官方介绍](https://openai.com/index/introducing-gpt-6-2-astra-sol/)；[研究发布页](https://openai.com/research/index/release/)）：推出面向高难度专业任务的 GPT-6.2 Astra，以及面向日常工作的 GPT-6.2 Sol。官方称两者都能在更少输出 token 的情况下完成更复杂的任务。Astra 的 API 输入与输出价格较 GPT-6 Astra 下调 20%，缓存输入再享 60% 折扣，定价为每百万 token 输入 8 美元、缓存输入 0.40 美元、输出 40 美元；Sol 维持 GPT-6.1 Sol 的 API 价格。官方还给出多项内部或合作基准结果，例如在多步骤专业工作测试 Agents' Last Exam 上，Astra 比 GPT-6 Astra 高 5.2 分、成本不到其三分之一，并比 Claude Fable 5.2 高 5.5 分、成本约为其 5%。上述基准与成本比较均为厂商自报。官方同时写明：两款模型在多数对齐评测上与 GPT-6 Astra 相近，但在两项测试中更常不主动说明挡住工作的障碍（例如缺失的文件或不可用的搜索工具）；团队已在 Codex 中加入指令以减少这类遗漏，并表示仍在继续调查。即日起，Plus、Pro、Enterprise 与 Edu 用户可在 ChatGPT Work 和 Codex 中使用两款模型；Pro 500 可为两者启用 Ultrafast，Pro 200 首次获得 Ultrafast，先从 Sol 开始；Enterprise 与 Edu 需工作区管理员开启。开发者可通过 API 调用 `gpt-6.2-astra` 与 `gpt-6.2-sol`，官方称发布时即可使用 Ultrafast。以上为厂商说明，未实测。

- **[英伟达：公布 2027 财年第三季度财报](https://investor.nvidia.com/news/press-release-details/2026/NVIDIA-Announces-Financial-Results-for-Third-Quarter-Fiscal-2027/default.aspx)**（11/17，[官方新闻稿](https://investor.nvidia.com/news/press-release-details/2026/NVIDIA-Announces-Financial-Results-for-Third-Quarter-Fiscal-2027/default.aspx)）：该季度截止 2026 年 10 月 25 日。官方披露营收 1158 亿美元，环比增长 20%，同比增长 103%；数据中心营收 1076 亿美元，同比增长 110%；GAAP 稀释每股收益 2.70 美元，非 GAAP 为 2.68 美元；GAAP 净利润 653 亿美元。新闻稿称 Vera Rubin NVL72 已开始出货，并称这是公司历史上最快的产品放量，相关机柜已在 CoreWeave、Google Cloud、Microsoft Azure、Oracle Cloud Infrastructure 与 Nebius 等伙伴处运行。公司对第四季度的营收指引为 1300 亿美元，上下浮动 3%，并写明该展望不计入来自中国的数据中心计算业务收入；GAAP 与非 GAAP 毛利率指引为 71.0% 至 72.0%。财报由临时 CEO 兼 CFO Colette Kress 代表公司发布。财务数字以官方新闻稿为准；展望为公司指引，不是已实现结果。

- **[微软：在 Ignite 发布一组新模型](https://microsoft.ai/news/microsoft-ignite-2026/)**（11/17，[MAI 官方博客](https://microsoft.ai/news/microsoft-ignite-2026/)）：微软 AI（MAI）宣布推出包括 MAI Cyber 2 Flash、MAI Code 2、MAI Code 2 Flash、MAI Image 2.7、MAI Realtime 1，以及用于 Dragon Copilot Transcribe 的 MAI Transcribe 2、Decision 1.1 在内的一组新模型，并称第二代加速器 Maia 200 已投入生产。官方将这组模型的重点放在价格与性能比，并给出多项与 OpenAI、Anthropic 等模型的对比数字，例如称 MAI Code 2 在若干企业编码基准上达到 GPT-6.1 Sol 约 98% 的表现、价格约为其 40%。上述对比、榜单名次与「世界最快 / 最准」等表述均为厂商自报。官方还称 MAI Code 2 已可在 GitHub Copilot 中使用，并推出 MAI Licensed Weights，允许客户在自己的 Azure 环境中定制和运行相应模型。以上为厂商说明，未实测。

- **[Vercel：Blob 支持按 TTL 自动删除](https://vercel.com/changelog/vercel-blob-now-supports-ttls-for-automatic-deletion)**（11/17，[官方 Changelog](https://vercel.com/changelog/vercel-blob-now-supports-ttls-for-automatic-deletion)）：写入 Blob 时可设置 `ttlDays`（1 至 730 天），到期后自动删除；也可用 `setTtl()` 延长、修改或清除已有对象的 TTL。官方称该参数适用于 `put()`、`copy()`、`putImage()`、分片上传和预签名上传，写入结果与 `head()` 会返回 `expiresAt`。Vercel CLI 65.16.0 及以上版本支持 `--ttl-days` 与 `vercel blob set-ttl`；SDK 需 `@vercel/blob@2.9.0`。官方还说明了 TTL 操作的计费规则。以上为厂商说明，未实测。
