> 核验日期：2026-11-15 北京时间。以下官方更新均标注为 11/13 发布，产品未实测。

## 要闻

- **[OpenAI：ChatGPT Wallet](https://openai.com/index/introducing-chatgpt-wallet)**（11/13，[官方公告](https://openai.com/index/introducing-chatgpt-wallet)）：面向美国 ChatGPT Pro 订阅用户（须年满 18 岁，并使用符合条件的美国发卡）在 dots 中滚动上线。用户预先添加卡片后，可让 dot 代为完成购买；每次付款前需核对商品、总额与所用卡片，并通过 Face ID 或指纹等安全验证。官方称，批准后由支付网络签发支付令牌（替代真实卡号），因此商家和智能体都看不到用户的真实卡片信息；合作方包括 American Express、Mastercard 与 Visa。用户保留符合条件的卡片奖励与争议保护，并直接与商家交易。官方同时表示，部分网站可能无意拦截智能体下单，并发布了面向商家的指引。当前仍是每次批准一笔交易；官方提到未来可能在限额等约束下预先授权，这是规划而非现已提供的能力。以上为厂商说明，未实测。
  <span hidden data-article-id="2026-11-15-chatgpt-wallet" data-tags="AI,产品,科技"></span>
- **[Google：Gemini 接入 Google Wallet](https://blog.google/innovation-and-ai/products/gemini-app/google-wallet-gemini-app/)**（11/13，[官方博客](https://blog.google/innovation-and-ai/products/gemini-app/google-wallet-gemini-app/)）：向美国所有 Gemini 应用用户滚动上线，可在 Personal Intelligence 的已连接应用中加入 Google Wallet，以便根据消费习惯回答理财、预算和订阅等问题；也可选择通过 Plaid 把银行或信用卡账户连到 Wallet，以获得更详细的洞察。官方明确写明：Gemini 只能读取账户信息，不能转移、管理或投资资金；用户可随时开关该连接。同期还提供 Memory Summary，用于查看和编辑 Gemini 记住的偏好与目标。以上为厂商说明，未实测。
  <span hidden data-article-id="2026-11-15-gemini-google-wallet" data-tags="AI,产品,科技"></span>
- **[llama.cpp 与 ggml：发布 v1.0.0](https://huggingface.co/blog/ggml-org/llama-cpp-v1)**（11/13，[官方博文](https://huggingface.co/blog/ggml-org/llama-cpp-v1) 与 [GitHub Release](https://github.com/ggml-org/llama.cpp/releases/tag/v1.0.0)）：ggml-org 将 `libllama` 与 `libggml` 提升到 1.0.0。官方写明，此后公开 C API 的不兼容变更会提升主版本号。该版本移除了已弃用的公开接口（发行说明列出包括 `llama_set_warmup` 在内的 35 个已弃用函数等），属于破坏性更新；同时加入 FP8 KV cache、主机内存 MoE expert cache、外部 PLE shard 加载，以及 `llama-server` 的若干安全加固。能力与兼容性以官方发行说明为准，未实测。
  <span hidden data-article-id="2026-11-15-llama-cpp-v1" data-tags="AI,开发,科技"></span>
- **[LangChain：完成 3 亿美元 C 轮融资](https://www.langchain.com/blog/series-c)**（11/13，[官方博客](https://www.langchain.com/blog/series-c)）：公司宣布以 30 亿美元估值融资 3 亿美元，由既有投资方 CapitalG 领投，新投资方 GIC、DFJ Growth 以及既有投资方 IVP、Sapphire Ventures 参与。官方称 LangSmith 已被 7,000 多家机构使用，并表示将在 11/20 发布新的 LangSmith 能力。机构使用规模与后续发布安排为厂商自报，未核实。
  <span hidden data-article-id="2026-11-15-langchain-series-c" data-tags="AI,科技"></span>
- **[Vercel：Token Pass 月度额度调至 150 美元](https://vercel.com/changelog/vercel-token-pass-now-includes-one-hundred-fifty-dollars-of-monthly-tokens)**（11/13，[官方 Changelog](https://vercel.com/changelog/vercel-token-pass-now-includes-one-hundred-fifty-dollars-of-monthly-tokens)）：在每月 30 美元团队费用不变的前提下，Token Pass 包含的 AI Gateway 额度由 80 美元上调至 150 美元，适用于官方列出的精选开源权重模型（如 Kimi K3、Kimi K3.1 Pro、GLM 5.3、GLM 5.3 Flash、DeepSeek V4.1 Flash）。额度按账期重置、不可结转；用尽后，普通 AI Gateway 密钥或 OIDC 回退到团队余额，而 Token Pass 范围的密钥会停止请求且不产生超额费用。官方写明这是面向 Pro 团队的 Early Access，名额有限。以上为厂商说明，未实测。
